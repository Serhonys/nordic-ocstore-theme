# NORDIC — тема для ocStore 3.0.4.1

Светлая витрина с чёрными акцентами. Это не скин поверх default: собственные Twig-шаблоны каталога, карточки, корзины, оформления заказа, кабинета, блога ocStore и модулей.

## Скачать установщик

Прямая ссылка на архив для админки:

https://github.com/Serhonys/nordic-ocstore-theme/releases/download/v1.0.0/nordic-ocstore-3.0.4.1.zip

## Установка

1. Админка → Расширения → Установщик → загрузите `nordic-ocstore-3.0.4.1.zip`.
2. Расширения → Расширения → Темы → NORDIC → Установить → Изменить.
3. Статус: Включено. Директория шаблона: `nordic`. Сохранить.
4. Система → Настройки → магазин → Тема: `nordic`. Сохранить.
5. Сбросить кэш темы (шестерёнка справа вверху).

Подробности — в [NORDIC.md](NORDIC.md).

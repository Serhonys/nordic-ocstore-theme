# NORDIC — тема для ocStore 3.0.4.1

Светлая витрина с чёрными акцентами. Это отдельная тема (`catalog/view/theme/nordic`), а не слой CSS поверх default. Свои Twig-шаблоны: шапка, подвал, меню, поиск, корзина, главная, категория, товар, поиск, акции, производители, сравнение, отзывы, оформление заказа, личный кабинет, информационные страницы, блог ocStore, основные модули, простые способы оплаты и письма.

Bootstrap CSS не подключается. Внешний вид задаёт `stylesheet/stylesheet.css`. jQuery 2.1.1, Bootstrap JS и `common.js` ядра остаются: без них не работают корзина, вкладки и оформление.

## Установка на ocStore 3.0.4.1

1. Расширения → Установщик → загрузите `nordic-ocstore-3.0.4.1.zip`.
   Если установщик недоступен, скопируйте содержимое папки `upload/` в корень магазина (туда, где лежат `admin`, `catalog`, `system`).
2. Расширения → Расширения → тип «Темы» → NORDIC → Установить → Изменить.
3. Статус: Включено. Директория шаблона: `nordic`. Сохраните.
4. Система → Настройки → изменить магазин → поле «Тема»: `nordic`. Сохраните.
5. Нажмите синюю шестерёнку справа сверху: обновите кэш модификаций и темы.

Код темы и имя папки должны совпадать (`nordic`). Размеры картинок читаются как `theme_nordic_*`.

Языки админки темы: en-gb, ru-ru, uk-ua.

## Что сознательно оставлено ядру

Платёжные модули со своим JavaScript (PayPal и аналоги) не переписаны. Если шаблона нет в теме, ocStore берёт default. В стиле NORDIC оформлены только простые способы: оплата при получении, банковский перевод, чек, бесплатный заказ.

Штатный модуль «Фильтр» — это группы чекбоксов. Ползунок цены, цвет и материал из прототипа витрины живут в демо-магазине. На живом ocStore их даёт OCFilter или атрибуты, подключённые к модулю фильтра. Кнопка `#button-filter` и классы ядра сохранены.

Карточки товара вписаны в шаблоны напрямую. Twig ocStore грузит один файл через ArrayLoader: `{% include %}` другого шаблона темы не сработает.

## Перенос на другие версии

**OpenCart 3.0.x (в том числе 3.0.3.8).** Общие шаблоны витрины те же. Отличия ocStore закрыты проверками:

- `robots`, `og_url`, `og_image` — только если контроллер их передал;
- `blog_menu` и шаблоны `blog/*`, `extension/module/blog_*` — нужны только ocStore с блогом, на чистом OpenCart не вызываются;
- jQuery берётся из `catalog/view/javascript/jquery/jquery-2.1.1.min.js`, этот файл есть и в OpenCart, и в ocStore.

Админ-контроллер темы — стандартный `extension/theme/*` OpenCart 3. На 3.0.x достаточно тех же файлов `upload/`.

**OpenCart 4.** Другое ядро: события вместо части контроллеров, другая структура админки тем, Twig подключается иначе. Этот архив на OpenCart 4 не ставится. Порт — отдельная поставка: те же CSS и разметка, новые точки входа темы.

## Контракт скриптов, который нельзя ломать

`nordic.js` подключается после `common.js` и не даёт ядру затереть вёрстку кнопок.

- Поиск: `#search input[name="search"]`, кнопка внутри того же родителя.
- Корзина: `#cart > button` и `#cart > ul`.
- Счётчики: `#wishlist-total`, `#compare-total`.
- Вид списка: `#grid-view`, `#list-view`. Сетка живёт в `#nt-products[data-view]`, а не в `.product-layout`.
- Валюта и язык: `#form-currency .currency-select`, `#form-language .language-select`, скрытые `code` и `redirect`.
- Товар: `#product`, `#button-cart`, `#input-quantity`, `.thumbnails`, `input-option{{ id }}`.
- Оформление: `#accordion` и панели `#collapse-checkout-option`, `#collapse-payment-address`, `#collapse-shipping-address`, `#collapse-shipping-method`, `#collapse-payment-method`, `#collapse-checkout-confirm` с классами `.panel .panel-heading .panel-title .panel-collapse .collapse .panel-body`.

Строки интерфейса, которых нет в языковых файлах ядра (кнопка «Каталог», «Фильтры»), подставляет `nordic.js` по атрибуту `data-nt` для ru, uk и en.
